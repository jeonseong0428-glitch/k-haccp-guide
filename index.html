01

처음 설정해요 · 관리자가 한 번

처음 한 번, 이것만 확인하세요

대부분은 보내 주신 해썹기준서·품목보고리스트·원재료 자료로 미리 세팅되어 있습니다. 우리 회사에 맞는지 확인하고 빠진 것만 채우세요.

  1. 1

    회사정보 확인

    기초등록회사정보 등록
    1. 회사정보·식품유형·해썹기준서 확인
    2. 회사수정
  2. 2

    직원 계정 만들기 (최대 10명)

    기초등록사용자 관리
    1. 사용자추가
    2. ID·비밀번호·알람사용여부·서명 이미지

    알람을 켜면 모바일 앱으로 미작성 알림이 갑니다.

  3. 3

    결재선 정하기

    기초등록결재선 관리

    일지별 검토자·승인자 지정. 처음엔 승인자가 모두 대표로 되어 있습니다. 검토자는 선택사항.

  4. 4

    알림시간·휴일 정하기

    기초등록설정 관리
    1. 알림주기시간(예: 16:30 이후 미작성 일지가 있으면 알림)·근무시간·휴일 요일
    2. 설정등록
  5. 5

    생산품목·원재료·거래처 확인

    기초등록생산품목 관리 / 원재료 관리 / 거래처 관리
    1. 품목보고리스트와 원재료 데이터가 이미 등록되어 있습니다. 추가만 하세요. 거래처는 양식다운로드
    2. 엑셀업로드로 일괄 등록

생산품목을 등록할 때 식품유형을 반드시 설정하세요. 없으면 유효성평가 대상에 안 보입니다.

02

아침에 출근했어요 · 매일 5분

로그인하면 오늘 할 일이 달력에 있습니다

첫 화면 '해썹캘린더 피드'의 빨간색(미작성)만 없애면 오늘 할 일은 끝입니다.

  1. 1

    로그인 후 달력 확인

    해썹캘린더 피드주기별점검일지

    오늘 날짜의 빨간 표시 = 아직 안 쓴 일지. 파란색 = 승인완료.

  2. 2

    일일 점검 일지 쓰기

    HACCP 관리 일지일일일지
    1. 작성
    2. 항목 체크 (막히면 우측 상단 AI가이드)
    3. '아니요'는 개선조치 기록
    4. 결재요청
  3. 3

    기타선행일지 탭 훑어보기

    해썹캘린더 피드기타선행일지

    보건증·검교정·자가품질·유효성평가의 남은 기간이 보입니다. 노란색 = 만료 임박.

AI가이드가 채운 내용은 예시입니다. 실제 점검 결과로 고친 뒤 결재요청하세요.

03

원료가 들어왔어요 · 입고 때마다

입고 등록 한 번이면 육안검사일지가 따라옵니다

원재료 입고를 등록하면 같은 날 육안검사일지에 입고 품목이 자동으로 생깁니다. 체크만 하면 됩니다.

  1. 1

    입고 등록

    원료수불·생산일지원재료입고등록
    1. 입고등록
    2. 품목코드(파란색) 선택 (없으면 간편등록)
    3. 입고처·입고일자·소비기한·입고량
    4. 저장
  2. 2

    육안검사일지 체크

    HACCP 관리 일지육안검사일지
    1. 작성
    2. 작성일자를 입고일로
    3. 자동 생성된 품목 체크
    4. 검사성적서·운반차량 온도기록지 첨부(모바일은 바로 촬영)
    5. 결재요청
  3. 3

    재고 확인

    원료수불·생산일지재고현황

    입고된 수량이 재고에 반영됐는지 확인. 엑셀·PDF로 저장 가능.

원재료입고·육안검사일지는 원스트라이크 아웃 항목입니다. 미작성 1회 적발로 인증이 취소될 수 있습니다.

지난 육안검사일지를 고치려면 원재료입고등록부터 수정하세요.

04

오늘 생산해요 · 생산 때마다

작업제품을 고르면 CCP 기록이 따라옵니다

생산할 제품을 먼저 고르세요. 관련 CCP 모니터링 항목이 자동으로 생기고, 작업시작을 누르면 2시간마다 기록행이 추가됩니다.

  1. 1

    작업제품 선택

    원료수불·생산일지작업제품선택
    1. 오늘 생산할 제품 선택
    2. 지시량 입력
    3. 저장

    제품이 녹색 '작업중'으로 바뀝니다.

  2. 2

    작업시작 → CCP 기록 → 작업종료

    원료수불·생산일지생산실적(CCP관리)등록
    1. CCP 항목 작업시작
    2. 2시간 간격 기록행에 측정값 기록
    3. 작업종료
    4. 생산량·수율 입력

    원재료가 품목제조보고 함량대로 자동 차감됩니다.

  3. 3

    CCP 모니터링 일지 결재

    HACCP 관리 일지CCP모니터링 일지관리
    1. 작성
    2. 날짜
    3. 일지명(예: 금속검출공정)
    4. 기록 확인
    5. 저장
    6. 결재작성
    7. 개선조치 유/무
    8. 결재요청
  4. 4

    생산일지 확인

    원료수불·생산일지생산일지

    생산량이 자동으로 들어와 있습니다. 확인 후 결재요청. 해썹 의무 외 품목은 생산등록으로 직접.

생산량을 입력하지 않으면 생산일지와 재고가 만들어지지 않습니다. 자동으로 들어간 CCP 값은 예시이니 실제 측정값으로 고치세요.

출고·재고 정리해요 · 출고 때·월말

거래기록서로 출고하고, 재고는 실사 후 조정

출고는 제품 거래기록서에서, 수량이 안 맞으면 재고조정에서 바로잡습니다.

  1. 1

    출고 등록

    원료수불·생산일지제품 거래기록서
    1. 거래등록
    2. 품목
    3. 거래처(없으면 간편등록)
    4. 거래일자·출고량(출고가능량 표시)
    5. 저장
    6. 결재요청
  2. 2

    재고 실사 후 조정

    원료수불·생산일지재고조정

    소비기한별 재고량을 보고 차이를 입력. 50개를 빼려면 -50처럼 음수로.

  3. 3

    원료 수불대장 보관

    원료수불·생산일지원료 수불대장
    1. 기간별 입·출고 조회
    2. 결재요청 또는 엑셀다운로드

    소비기한별 재고현황도 엑셀·PDF 가능.

생산에 쓴 원재료를 따로 차감하려면 원재료사용등록에서 사용등록 → 사용일자·사용량 → 저장.

결재해야 해요 · 검토자·승인자

결재함에서 승인 / 반려, 끝

결재선이 정해져 있으면 작성자가 결재요청한 문서가 결재함에 쌓입니다.

  1. 1

    결재함 열기

    결재함

    기간·관리항목·문서상태로 조회. 목록에서 바로 승인 / 반려, 또는 상세 확인 후 수정 / 반려 / 승인.

  2. 2

    반려됐을 때 (작성자)

    반려 문서
    1. 내용 수정
    2. 결재요청으로 재상신

    작성자는 수정·삭제할 수 있습니다.

  3. 3

    결재선 바꾸기

    기초등록결재선 관리

    일지별 검토자·승인자 변경.

승인이 끝난 일지는 수정할 수 없습니다. 고쳐야 하면 반려 후 수정하세요.

07

주간·월간·교육 · 주기별

주기가 오면 달력에 뜹니다. 같은 방식으로 쓰세요

작성 주기는 해썹기준서 기준이고 바꿀 수 있습니다. 쓰는 방법은 일일일지와 같습니다.

  1. 1

    주간·월간·연간 일지

    HACCP 관리 일지주간일지 / 월간일지 / 연간일지
    1. 작성
    2. 체크 (필요 시 AI가이드)
    3. 결재요청

    2·3개월 주기 일지는 별도로 세팅해 드립니다.

  2. 2

    교육훈련일지

    HACCP 관리 일지교육훈련
    1. 연간 교육계획에 맞춰 교육요약이 자동 표시
    2. 사진 첨부(PC 카메라 아이콘 / 모바일 촬영)
    3. 참석자 확인
    4. 특이사항
    5. 결재요청

    기준: 해썹 종업원 교육 연 4시간, 자체 위생교육 월 1시간.

  3. 3

    회사 자체 양식(기타일지)

    HACCP 관리 일지기타일지
    1. 한글(HWP) 양식 업로드
    2. 양식등록
    3. 구분·제목
    4. 등록

    여백은 좌5·우5·위10·아래5mm, 머리말·꼬리말 0mm.

만료일 놓치면 안 돼요 · 보건증·검교정·검사

차기 일자만 넣어 두면 남은 날짜를 세어 줍니다

메인 화면 '기타선행일지' 탭에서 한눈에 보고, 지정한 날짜에 모바일 앱 알림을 받습니다.

  1. 1

    보건증

    HACCP 관리 일지보건증
    1. 생산 투입 인원 전원. 유효기간 등록
    2. 임박 시 사원번호가 노란 바탕 빨간 글자
  2. 2

    검교정

    HACCP 관리 일지검교정일정
    1. 실시 후 갱신등록

  3. 3

    자가품질검사 · 유효성평가

알림 값을 바꾼 뒤에는 반드시 수정을 눌러야 저장됩니다.

10

막혔을 때

자주 묻는 질문

여기 없는 질문은 카카오 1:1 상담으로 물어보세요.

Q1생산일지나 재고가 안 생겨요.
생산실적(CCP관리)등록에서 작업종료 후 생산량을 입력했는지 확인하세요. 생산량이 없으면 생산일지·재고현황이 생성되지 않습니다.
Q2결재 승인된 일지를 고치고 싶어요.
승인이 끝난 일지는 수정할 수 없습니다. 반려 후 수정하세요. 일지는 작성자만 수정·삭제할 수 있습니다.
Q3지난 육안검사일지를 고치려면요?
육안검사일지는 원재료입고등록에서 자동으로 만들어집니다. 원재료입고등록에서 먼저 수정하세요.
Q4CCP 양식을 고쳤는데 이미 있는 일지에는 반영이 안 돼요.
CCP 양식은 해당 일자 계획이 생성될 때 고정됩니다. 고친 뒤 생성되는 일지부터 반영되고, 이미 생성된 미작성 일지에는 이전 문구가 남습니다. 이미 생성된 일지까지 바꿔야 하면 카카오 1:1 상담으로 요청해 주세요.
Q5"CCP 양식 관리" 메뉴가 안 보여요.
기록일지 관리 › CCP 양식 관리 메뉴는 업체 관리자 계정으로 로그인해야 보입니다.
Q6쉬는 날에도 일지가 잡혀요.
기초등록 › 설정 관리에서 휴일 요일을 지정하고 설정등록을 누르세요.
Q7알림 날짜를 바꿨는데 그대로예요.
알림 값을 바꾼 뒤 반드시 수정을 눌러야 반영됩니다.
Q8로그인할 때 팝업이 떠요.
공지·결제 안내 팝업입니다. 내용을 확인한 뒤 닫고 로그인하세요.
Q9바코드로 입출고할 수 있나요?
바코드는 별도 개발 사항입니다. 카카오 1:1 상담으로 문의해 주세요.
Q10유효성평가는 언제 하나요?
품목 유형과 상관없이 연 1회, 생산(공정) 전/후로 나눠 1회. 자가품질검사와는 별개입니다.
